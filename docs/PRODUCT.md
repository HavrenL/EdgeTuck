# 产品约定

本文说明当前产品方向与必须保留的行为。当前能力和使用方法见 [README](../README.md)。

## 文件与分类

- 每个抽屉绑定一个普通文件夹，同时保存路径和文件系统身份。新建时必填英文目录名，仅允许以英文字母开头的字母和数字，实际目录为 `ET` 加输入名；标题可使用中文。前缀不作为归属证明。
- 新用户默认存放在 `%USERPROFILE%\EdgeTuck`，也可选择其他目录或桌面模式。升级保留已保存的目录与绑定。
- 普通拖入、拖回桌面和跨抽屉转移是真实文件移动；Ctrl 拖入为复制。同名不自动覆盖或合并。
- 新抽屉的标题独立于英文目录名，改标题不改路径。已有目录保留原来的标题同步方式，可通过“设置英文目录名…”主动转换，确认后改目录并更新项目路径和最近使用记录。外部改名按目录身份重新连接，英文目录保留标题。身份不符时停止操作，不自动认领替代目录。
- 不承诺修复其他软件的绝对路径配置；收纳、改目录名或迁移可能使程序、项目环境及快捷方式的旧路径失效。英文分类目录不改变上级目录或项目内部名称，开发工具需要全英文路径时应自行选择英文存放位置。
- 解散抽屉保留普通文件夹和内容，支持撤销最近一次解散。删除程序不删除分类文件。
- 桌面新建文件留在桌面，抽屉中新建文件保存在对应文件夹。旧版本引用只有在用户主动归档后才移动。
- `Delete` 表示移回桌面；经典系统菜单中的“删除”执行系统文件删除。

## 存储迁移

“保存新抽屉的位置”只改变以后创建抽屉的默认位置；迁移必须由用户主动触发。

同一实际磁盘卷使用整文件夹移动，并在操作前写入恢复记录。跨卷使用复制、SHA-256 校验、提交新绑定和回收旧目录的流程。取消与失败按事务阶段处理；无法确认身份或恢复遇到冲突时保留相关文件，不猜测哪一份可以删除。

程序目录、配置目录和用户收纳目录分开。测试必须使用自己创建的临时文件，不迁移真实用户资料。

## 原生桌面

- 保留桌面网格、排列选项、框选和右键菜单，不切换全局桌面图标开关，不更改文件隐藏属性。
- 桌面模式仅停放明确绑定且身份匹配的分类文件夹图标。自动排列开启时保留可见图标；屏幕外图标仍可能参与桌面全选。
- 抽屉属于桌面层，普通窗口可以覆盖它。设置中的临时预览与桌面正常使用分别验证。
- 当前围绕主显示器布局；不将已有的 DPI 感知声明描述为完整多显示器支持。

## 抽屉与设置

- 支持左、右、顶部；悬停展开，离开后收起，菜单、拖放和调整大小期间保持打开。
- 外框沿桌面网格吸附，内部图标的绘制与命中使用同一布局。外框视觉留缝不改变占位。
- 提供浅色、深色、跟随系统，液态玻璃和纯色材质，以及动画开关。
- 实时玻璃覆盖展开、收回和收起边缘；可见的窄边继续更新，被普通窗口完全覆盖时暂停捕获。开销按实际场景测量。
- 设置分为“我的抽屉”“外观”“常规”。关闭设置窗口后保留托盘，通过“退出轻屉”完全退出。
- 每个抽屉独立排序；最近使用只记录成功提交的双击打开请求，完全收回后更新。
- 文件菜单采用经典 Shell 菜单，不称作完整的 Windows 11 新式菜单。

## 实现与验证

保持原生、事件驱动。性能目标与实测结果分别记录，不用短时空闲数据推断长期稳定性。新增常驻线程、计时器或钩子前，说明其必要性并测量。

常规应用、隔离测试和展示素材各自使用独立数据。菜单扩展只在辅助进程加载；开始执行命令后，不因菜单加载超时而终止文件操作。

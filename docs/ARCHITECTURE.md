## 窗口与绘制

每个抽屉使用一个无系统边框的原生窗口，由 Windows Composition 移动合成内容。图标与文字用 Direct2D / DirectWrite 绘制。纯色动画可以独立于背景捕获运行。

实时模式通过 Windows Graphics Capture 取得 Explorer 桌面宿主的内容，抽屉共享 GPU 背景，各自处理局部模糊、曲面折射、色散和边缘高光。正常渲染不将帧回读到 CPU，也不保存桌面截图。

收起时仅处理露出的窄边及材质所需输入区域，前景图标、文字和选中高光一起淡出。普通应用局部遮挡不会冻结整个抽屉；桌面完全被覆盖时暂停捕获。关闭实时背景后使用兼容快照模式，不跟随动态背景。

HLSL 通过 Windows SDK 的 FXC 在构建时编译并嵌入程序。运行时不依赖浏览器、.NET 或独立着色器编译器。捕获兼容性、GPU 开销和实际延迟仍需按运行环境验证。

## 文件与身份

配置记录文件夹路径及文件系统身份，文件内容始终位于普通文件夹中。新建目录时避免重名；原路径出现其他目录时不自动认领。外部文件变化通过 Shell 通知同步，图标与缩略图在后台读取并缓存。

配置格式 8 为每个抽屉保存英文目录标记；旧格式 1–7 保留路径和原来的名称同步方式。新建窗口强制校验英文目录名，只允许字母和数字、首字符为字母。新目录名使用 `ET` 前缀，碰撞时仅追加数字。英文目录的标题改名不执行文件夹移动，外部目录改名按身份重新连接时不覆盖标题；显式目录改名复用身份检查、无覆盖移动及保存失败回退。

同卷迁移提前保存恢复记录，再执行不覆盖目标的整目录移动。跨卷先复制并核对内容，保存新绑定后再回收旧目录。恢复时核对身份，冲突时保留文件和记录。

最近使用时间随路径调整；展开期间不立即重排，完全收回后才应用排序结果。

## 桌面集成

程序将抽屉放在原生桌面上方、普通窗口下方。桌面模式通过定位明确绑定的分类文件夹图标释放可见位置；不把这种停放行为描述为系统提供的逐项隐藏功能。

Win+D 或任务栏“显示桌面”会在切换前景窗口之后抬高 Explorer 桌面。程序通过既有的窗口重排事件监听，在抽屉被桌面覆盖时恢复其顺序，并合并重复请求；普通应用仍可覆盖抽屉，不需要持续轮询。

“此电脑”入口使用当前用户的 Shell 文件夹实例注册，指向保存的收纳根目录。它不是云同步提供方，也不需要向 Explorer 安装自定义 DLL。

对原生桌面逐项过滤的探索未形成可靠方案。调研过程见 [参考来源](REFERENCES.md)，本版本采用真实文件夹归档。

## 菜单隔离

文件菜单扩展只在 `--shell-menu=` 辅助进程加载。主进程按当前文件请求系统经典菜单，加载超时或崩溃后提供基本操作和重试。

未执行命令的辅助进程可以短暂复用或在超时后退出；进入执行阶段后，不回收正在处理文件操作的进程。异步 Shell 工作使用进程与线程生命周期引用保护。

辅助进程不通过 `STARTF_USESHOWWINDOW / SW_HIDE` 传递隐藏启动状态，避免原生“打开文件所在位置”命令将该状态应用到 Explorer 窗口。

## 配置与开发隔离

常规设置位于 `%LOCALAPPDATA%\EdgeTuck\settings.dat`。开发工具与 Explorer 启动上下文可能看到不同的配置内容，正常验收统一通过已有 Explorer 会话启动。

自动窗口测试使用 smoke 分支，不加载或保存日常配置。展示工具在同一 UI 实现上创建独立示例数据和背景，详见 [展示素材](SHOWCASE.md)。
